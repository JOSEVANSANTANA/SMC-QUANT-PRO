========================================================================
  SMC QUANT PRO v2.24.0 — MAC (Apple Silicon M1 / M2 / M3)
  Comece por aqui. Leva uns 10 minutos, e quase tudo é automático.
========================================================================

PASSO 1 — DESCOMPACTE E COLOQUE A PASTA NUM LUGAR FIXO
------------------------------------------------------
Arraste a pasta "SMC_QUANT_PRO" para dentro de Documentos.
Depois de instalar, NÃO mova mais a pasta de lugar.

ATENÇÃO: no Finder a pasta aparece como "Documentos", mas no disco ela
se chama "Documents" (em inglês). É normal do macOS. Se for digitar um
caminho no Terminal, use ~/Documents.


PASSO 2 — INSTALE O PYTHON CERTO  (obrigatório, 5 min)
-------------------------------------------------------
O Python que já vem no Mac NÃO SERVE — ele não traz o Tk, que é a
biblioteca da interface, e o programa nem abre.

  1. Abra:  https://www.python.org/downloads/macos/
  2. Baixe: "macOS 64-bit universal2 installer" do Python 3.12
  3. Instale normalmente (Avançar, Avançar).


PASSO 3 — INSTALE O NODE.JS  (obrigatório para o motor)
--------------------------------------------------------
Baixe o instalador ARM64 (Apple Silicon) em https://nodejs.org
— pegue a versão LTS.

Se você já usa o Homebrew, "brew install node" também serve.


PASSO 4 — DOIS CLIQUES EM:  INSTALAR_MAC.command
-------------------------------------------------
Ele confere tudo e instala as bibliotecas sozinho. Vai abrir uma janela
preta com o passo a passo — é assim mesmo.

SE O MAC RECUSAR ABRIR ("não pode ser aberto porque é de um
desenvolvedor não identificado"):

  → Clique com o BOTÃO DIREITO no arquivo → Abrir → Abrir de novo.

  Se ainda assim recusar, abra o app Terminal e cole isto (uma linha):

      chmod +x ~/Documents/SMC_QUANT_PRO/*.command

  Depois tente os dois cliques de novo.


PASSO 5 — AS DUAS PERMISSÕES  (não pule — conceda AS DUAS)
----------------------------------------------------------
  Ajustes do Sistema → Privacidade e Segurança →

    1) GRAVAÇÃO DE TELA   → "+" → adicione o programa
    2) ACESSIBILIDADE     → "+" → adicione o programa

  Depois FECHE e ABRA o programa de novo.

O QUE ADICIONAR:
  • se você abre pelo ABRIR_SMC_QUANT_PRO.command → adicione o TERMINAL
  • se você criou o aplicativo (CRIAR_APP.command) → adicione o
    "SMC Quant Pro"
  • na dúvida, adicione OS DOIS. Não faz mal nenhum.

POR QUE DUAS: o título da janela ("Google Chrome — Tradovate") pode vir
por qualquer uma das duas. A Gravação de Tela às vezes não pega quando o
programa é aberto por um .command — o macOS atribui a permissão ao
processo "responsável", e nesse caminho ela se perde sem avisar. A
Acessibilidade é o segundo caminho, e costuma funcionar quando o
primeiro falha.

SEM NENHUMA DAS DUAS: o macOS NÃO DÁ ERRO. Ele entrega a lista de
janelas SEM OS TÍTULOS (só o nome do aplicativo) e a captura sai PRETA.
É a causa número 1 de "instalei e não funciona".

Para conferir: clique em "🩺 Diagnosticar janelas" na aba Motor. Ele diz
qual das duas está respondendo e mostra o título de cada janela.

PASSO 6 — ABRIR O PROGRAMA
---------------------------
Dois cliques em:  ABRIR_SMC_QUANT_PRO.command

Na aba Motor:
  • cole a chave da Gemini (ela vai para o Chaveiro do Mac, não fica em
    texto no arquivo de configuração);
  • na lista de gráficos, escolha a janela. No Mac ela aparece como
    "Google Chrome — Tradovate" (o aplicativo vem primeiro de propósito:
    sem a permissão do Passo 5 o título vem vazio, e assim você ainda
    consegue escolher pelo aplicativo);
  • LIGAR MOTOR.

Na PRIMEIRA vez que ligar o motor ele instala as dependências do Node
sozinho (1 a 2 minutos, precisa de internet). Isso só acontece uma vez.


========================================================================
  DEIXAR COMO APLICATIVO (ícone no Launchpad e no Dock)
========================================================================
Dois cliques em:  CRIAR_APP.command

Sai em segundos. Ele monta o "SMC Quant Pro.app" dentro de Aplicativos,
apontando para esta pasta. Não é uma cópia: quando eu te mandar uma
versão nova, você troca os .py aqui e o aplicativo já usa a nova, sem
recriar nada.

Depois: abra uma vez, botão direito no ícone do Dock → Opções →
Manter no Dock.

⚠️ A PERMISSÃO É POR APLICATIVO. Você liberou a Gravação de Tela para o
   TERMINAL. Aos olhos do macOS o aplicativo é OUTRO programa e precisa
   da própria permissão:

     Ajustes do Sistema → Privacidade e Segurança → Gravação de Tela
       → botão "+" → Aplicativos → "SMC Quant Pro" → e ABRA o app de novo

⚠️ NÃO MOVA esta pasta depois de criar o aplicativo. Ele aponta para ela.
   Se precisar mover, rode o CRIAR_APP.command de novo no lugar novo.


========================================================================
  PAINEL DE LICENÇAS  (só você usa — não é para cliente)
========================================================================
Dois cliques em:  ABRIR_PAINEL_LICENCAS.command

Abre no navegador. Nele você:
  • CRIA licenças (com gerador de chave sem letras que o cliente confunde:
    sem I, sem O, sem 0 e sem 1);
  • VÊ quem ativou, em qual máquina e quando foi o último acesso;
  • REVOGA uma licença (o programa do cliente para na próxima validação);
  • LIBERA a máquina quando o cliente troca de computador — a chave volta
    a valer e se casa com a próxima máquina que ativar.

O painel conversa com o SEU servidor, que já está no ar em
https://smc-quant-pro.onrender.com

Ele pede a SENHA DE ADMINISTRADOR (o ADMIN_TOKEN configurado no servidor).
Marque "lembrar nesta máquina" para não digitar toda vez — fica guardada
só neste Mac, no navegador, e some se você desmarcar.

⚠️ NÃO mande o arquivo painel_licencas.html para ninguém. Quem tiver ele
   mais o token cria e revoga licenças no seu lugar.

SOBRE A PRIMEIRA CONEXÃO DO DIA: o Render, no plano gratuito, hiberna o
servidor quando fica parado. A primeira chamada pode levar uns 50
segundos para acordá-lo. O painel avisa isso na tela em vez de parecer
travado — é só esperar.

A pasta "servidor_licencas" tem o código do servidor, caso um dia você
queira rodá-lo em outro lugar. Você NÃO precisa dela no dia a dia.

O MICROFONE NAO PRECISAVA DO NUMPY — E NUNCA PRECISOU.

  instalar nada. Nao precisa rodar o INSTALAR_MAC.command de novo.
